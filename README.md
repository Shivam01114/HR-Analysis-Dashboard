# HR-Analysis-Dashboard
This project is an interactive HR Analytics Dashboard designed to provide insights into key HR metrics. Built using Power BI, it helps HR teams and managers make data-driven decisions by visualizing data related to employee performance, attrition rates, recruitment trends, and other essential HR KPIs.

Features

Employee Performance Analysis
Attrition Rate Visualization
Recruitment Trends Tracking
Interactive Filters for Dynamic Analysis
Clean and Intuitive UI for Better Decision-Making

Tools Used
Power BI: For data visualization and dashboard creation
